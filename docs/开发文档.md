# 书友席 开发文档

面向本地开发与打包发布的操作手册。产品定位见 [产品设计_V2.md](产品设计_V2.md)，架构与里程碑见 [技术方案与实现计划.md](技术方案与实现计划.md)。

当前版本：`0.1.0`（`package.json` 与 `src-tauri/tauri.conf.json` 保持一致）。

---

## 1. 环境要求

| 组件 | 要求 |
| --- | --- |
| Node.js | 建议 **≥ 20**（Vite 7 常见要求；仓库未钉 `engines`） |
| 包管理 | **pnpm**（与 `pnpm-lock.yaml` 一致） |
| Rust | **≥ 1.90**（见 `src-tauri/Cargo.toml` 的 `rust-version`），通过 rustup 安装 **stable** |
| macOS 桌面 | Xcode Command Line Tools |
| Android | Android Studio，以及 SDK、NDK、**JDK 17** |

### 1.1 仅前端 / 浏览器开发

安装 Node.js 与 pnpm 即可，可跑 `pnpm dev`、`pnpm test`、`pnpm lint`。

### 1.2 桌面端（Tauri）

1. 安装 [rustup](https://rustup.rs/)，确认 `rustc --version` ≥ 1.90。
2. macOS：安装 Xcode Command Line Tools（`xcode-select --install`）。
3. Windows：按 [Tauri 前置条件](https://v2.tauri.app/start/prerequisites/) 安装 Visual Studio C++ 构建工具与 WebView2。

### 1.3 Android 真机 / 打包

1. 安装 Android Studio，并安装 SDK、NDK、JDK 17。
2. 配置环境变量（路径按本机安装位置调整）：

```bash
export JAVA_HOME=...
export ANDROID_HOME=...
export NDK_HOME=...   # 或 ANDROID_NDK_HOME，与本机约定一致
```

3. 添加 Rust Android targets：

```bash
rustup target add aarch64-linux-android armv7-linux-androideabi i686-linux-android x86_64-linux-android
```

4. 验收：在仓库根目录执行：

```bash
pnpm tauri info
```

输出中相关工具链应无报错。

## 3. 配置说明

### 3.1 API Key（日常开发）

运行时 API Key **在 App 设置页填写**，经平台层写入本地存储（Tauri Store / Web 实现）。密钥只存本机，不要写入代码、日志或备份。

日常开发 **不必** 配置 `.env`。设置页提供「测试连接」，可分别验证 JSON 调用与流式调用。

### 3.2 `.env`（可选）

[`.env.example`](../.env.example) 中的 `DEEPSEEK_API_KEY` 仅供遗留本地脚本等可选用途。若使用：

```bash
cp .env.example .env.local
# 编辑后填入密钥
```

`.env`、`.env.local`、`.env.*.local` 已在 `.gitignore` 中，勿提交真实密钥。

### 3.3 Android 真机热更新（`TAURI_DEV_HOST`）

真机调试时，开发服务器需对本机局域网 IP 可访问。Vite 已支持 `TAURI_DEV_HOST`：

- 开发服务端口：**1420**（`strictPort: true`）
- HMR：**1421**（在设置了 `TAURI_DEV_HOST` 时）

按本机网卡 IP 设置，例如：

```bash
export TAURI_DEV_HOST=192.168.1.10
pnpm tauri android dev
```

## 4. 启动与调试

日常优先在浏览器开发同一套 Web 代码；需要验证原生能力（文件选择、plugin-http、Store 等）时再跑桌面或 Android。

| 场景 | 命令 | 说明 |
| --- | --- | --- |
| 浏览器 | `pnpm dev` | 打开 `http://localhost:1420`，用浏览器 DevTools 调试 |
| 桌面 | `pnpm tauri dev` | 自动执行 `beforeDevCommand`（`pnpm dev`），打开「书友席」窗口 |
| Android 真机 | `pnpm tauri android dev` | 先开启 USB 调试，用 `adb devices` 确认已连接 |
| 单测 | `pnpm test` | Vitest 单次跑完（`jsdom` + `fake-indexeddb`） |
| 单测监视 | `pnpm test:watch` | 改代码后自动重跑 |
| Lint | `pnpm lint` | ESLint |
| 格式化 | `pnpm format` | Prettier 写回 |

### 4.1 建议调试路径

1. **业务与 UI**：`pnpm dev` + 浏览器 DevTools；在设置页填入 Key 后测模型连通。
2. **原生能力**：`pnpm tauri dev`（桌面）或 `pnpm tauri android dev`（真机）。
3. **纯逻辑**：`src/core`、`src/db` 用 `pnpm test` / `pnpm test:watch` 覆盖。

### 4.2 分层约定（改代码时注意）

- 业务代码不直接 `import` `@tauri-apps/*`，统一经 `src/platform`；由 ESLint `no-restricted-imports` 强制。
- `src/core` 保持纯 TypeScript，不依赖 Vue、Dexie、Pinia、Router、Tauri。

### 4.3 常见问题

| 现象 | 排查 |
| --- | --- |
| `pnpm dev` 起不来 / 端口占用 | 1420 被占用时 Vite 会失败（`strictPort`）；结束占用进程或改配置后再开 |
| `pnpm tauri info` 报错 | 检查 Rust 版本、Xcode CLT / Windows 构建工具、Android SDK/NDK/JDK 17 与环境变量 |
| Android 真机无设备 | `adb devices`；开启开发者选项与 USB 调试；无线调试易掉线时可改用数据线 |
| 真机连不上开发服 | 确认 `TAURI_DEV_HOST` 为本机局域网 IP，手机与电脑同一网段，防火墙放行 1420/1421 |
| 模型调用失败 | 设置页检查基址、模型名与 Key；App 内走 `plugin-http`，浏览器可直连（DeepSeek CORS 已验证） |
| macOS 未签名安装包打不开 | Release 安装后右键图标选择「打开」放行（见第 5 节） |

## 5. 构建 Release 包

发版前将 `package.json` 与 `src-tauri/tauri.conf.json` 的 **version** 改为同一语义化版本。升级安装前建议在 App 内先做一次 JSON 备份。

`pnpm tauri build` / `pnpm tauri android build` 会先执行 `beforeBuildCommand`（`pnpm build`：`vue-tsc -b && vite build`），前端产物输出到 `dist/`。

### 5.1 仅前端静态资源

```bash
pnpm build
```

产物在 `dist/`。单独预览可用 `pnpm preview`。正式分发以 Tauri 安装包为准。

### 5.2 当前桌面平台

在目标操作系统上执行：

```bash
pnpm tauri build
```

| 本机构建环境 | 典型产物 | 注意 |
| --- | --- | --- |
| macOS | dmg 等（`bundle.targets` 为 `all`） | **未签名**；首次打开右键「打开」放行 |
| Windows | NSIS 等安装包 | 本机需具备 Tauri Windows 前置条件；**未签名**；SmartScreen 可能提示「仍要运行」 |

技术方案中规划了用 GitHub Actions（tauri-action）在 Windows 上出包；**当前仓库尚未落地该 workflow**，请以本机 `pnpm tauri build` 为准。

### 5.3 Android APK

```bash
pnpm tauri android build --apk
```

- Debug 包 applicationId 带后缀 `.debug`（见 `tauri.conf.json` 的 `bundle.android.debugApplicationIdSuffix`），可与正式包并存。
- **正式签名**：首次用 `keytool` 生成 keystore，存放在仓库之外并备份。密钥库丢失后新版本无法覆盖安装旧版本，只能卸载重装（本地数据会丢）。签名配置写在 `src-tauri/gen/android` 的 Gradle 中，密码从**本地环境变量**读取，勿提交密钥与密码。细节见技术方案第 9 节。

产物 APK 传到手机安装即可。

### 5.4 命令速查

| 命令 | 用途 |
| --- | --- |
| `pnpm build` | 前端类型检查 + Vite 生产构建 |
| `pnpm tauri build` | 当前桌面平台安装包 |
| `pnpm tauri android build --apk` | Android APK |
