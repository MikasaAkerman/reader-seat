# 世界文学十年阅读与评论输出计划

> 目标不是"读完"，是**十年后你有能力就任何一部经典即兴聊上20分钟，讲出别人没讲过的角度**。
> 所以这版计划的核心变化是：每一站都配了"输出任务"。读书是原料，评论是产出物。没有输出的阅读，在这份计划里不算数。

## 每站固定流程

1. 精读作品，读时只批注，不查任何评论。
2. 每部写300字微评：一个判断、一个文本证据、一个保留。此时不看评论。
3. 拆解主范文：它的论点怎么立、证据怎么排、哪里转折。先看示范。
4. 仿作：用同样的论证结构写另一部作品的一个片段，约500字。
5. 读反方短文，写"我同意哪里、不同意哪里"。
6. 写正式评论（1500到2500字），必须有保留意见，并回应反方。
7. 在评论词汇表里记2到3个新工具。

每站还要对读一处两个译本的同一段，写200字：哪个更好，具体好在哪。

## 十二站

**1｜地基：细节与潜文本**
- 核心问题：一个判断如何落到具体的词句上？
- 精读：《老人与海》（吴劳译与张爱玲译对读）；契诃夫短篇十余篇（汝龙译）；张爱玲或沈从文短篇两三篇（读原文，练中文句子级细读）。陪衬：海明威《过河入林》（评论界公认的弱作，如有中译本），同一作者强弱作对读，最能校准"好"的刻度。我删去了《动物农场》，它寓意太直白，不利于练细读。
- 范文 / 反方：纳博科夫《优秀读者与优秀作家》；反方是桑塔格《反对阐释》（程巍译）。你从第一站起就要面对"细读"与"反对阐释"的分歧，并选定自己的立场。伍德《小说机杼》（黄远帆译）快读一遍，只标出之后要回读的章节。
- 输出：《老人与海》评论，不许出现"象征"，至少3处具体细节。工具：冰山、潜文本。

**2｜现实主义：叙述者的声音**
- 核心问题：叙述者在哪里退场，人物的声音在哪里浮现？
- 精读：《傲慢与偏见》（王科一译）；《红与黑》（罗新璋或郝运译）；《包法利夫人》（李健吾与周克希译对读）；《儒林外史》（读全书）。陪衬：小仲马《茶花女》，同样写女性、欲望与金钱，感伤和冷静一比就见分晓。对照：《儒林外史》↔果戈理《死魂灵》（满涛译，鲁迅的译本也值得翻一翻），都是讽刺人物长廊。
- 范文 / 反方：纳博科夫论福楼拜；反方是奥尔巴赫《摹仿论》中论斯丹达尔、福楼拜的章节。回读伍德论自由间接引语的章节。
- 输出：500字自由间接引语分析（用《包法利夫人》原文）；正式评论比较《包法利夫人》与《茶花女》。工具：自由间接引语、白描式反讽。

**3｜史诗、悲剧与框架：故事怎么被组织**
- 核心问题："发现—突转"这类结构如何运作？叙事模式如何塑造经验？
- 精读：《奥德赛》全书（王焕生散文译，陈中梅诗体译，对读卷9）；《俄狄浦斯王》《安提戈涅》（罗念生译）；《史记·项羽本纪》（原文）；《神曲·地狱篇》（田德望译）；《一千零一夜》选读（纳训译）。《诗学》（罗念生或陈中梅译）当工具书用，不当范文。原计划用《庄子》《山海经》《薄伽梵歌》做对照，是在拿哲学和神话比戏剧，我换成了同类叙事的《项羽本纪》。
- 范文 / 反方：奥尔巴赫《奥德修斯的伤疤》（《摹仿论》第一章），从一个具体段落推出大论断的典范，谈的又正是你刚读的《奥德赛》。第二篇是本雅明《讲故事的人》，它谈的是列斯科夫，把它当"叙事与经验"的方法来读，别当对某部作品的评论。
- 输出：比较评论《俄狄浦斯王》与《项羽本纪》："发现""突转"在后者里有没有？没有的话，它靠什么起作用？工具：发现与突转、环形结构、框形叙事。

**4｜反讽与现代自我**
- 精读：《堂吉诃德》（杨绛译，上部读全，下部选读）；《哈姆雷特》（朱生豪与卞之琳译对读几段独白）；《西游记》（读全书）。对照：《西游记》↔《堂吉诃德》，旅途结构加戏仿。
- 范文 / 反方：纳博科夫《堂吉诃德》讲稿；反方是艾略特《哈姆雷特和他的问题》，他直言这部戏是艺术上的失败。
- 输出：《哈姆雷特》评论，必须回应艾略特的判断（支持或反驳皆可），并以戏剧反讽为论证核心。工具：三种反讽、元叙事。

**5｜一部小说如何装下一个时代（重点站）**
- 精读：《红楼梦》（人民文学出版社校注本，前80回精读，后40回作为评价题）；《战争与和平》（草婴译）；《源氏物语》选卷（林文月或丰子恺译）作为第三极。陪衬：一部明清才子佳人小说（如《玉娇梨》），看曹雪芹在第一回批判的究竟是什么。
- 范文 / 反方：王国维《红楼梦评论》，加脂砚斋批语（传统评点如何细读）；反方是余英时《红楼梦的两个世界》或张爱玲《红楼梦魇》；托尔斯泰一侧读伯林《刺猬与狐狸》。
- 输出：2000字以上的比较长文：全景史诗与网状家族叙事。再加一道评价题：后40回哪几处不如前80回、哪几处其实不差，用文本说话。工具：全知介入、网状叙事。

**6｜复调与精神极限**
- 精读：《罪与罚》（岳麟译，或朱海观、王汶译，可对读）；《卡拉马佐夫兄弟》（荣如德译）。
- 范文 / 反方：巴赫金《陀思妥耶夫斯基诗学问题》（白春仁、顾亚铃译）；反方是纳博科夫对陀氏的贬斥（《俄罗斯文学讲稿》）。
- 输出：1500字，用"复调"分析至少三个角色的声音，并回应纳博科夫的指责。工具：复调。

**7｜边缘人与叙述的可靠性**
- 精读：《简·爱》（祝庆英译）；《呼啸山庄》（杨苡译或方平译，对读开篇）；《悲惨世界》选读（李丹、方于译）。原计划把《简·爱》当不可靠叙述的例子，我觉得不太准，真正典型的是《呼啸山庄》里洛克伍德与耐莉的层层转述。
- 范文 / 反方：伍尔夫《简·爱与呼啸山庄》，直接评这两部，还带着明确的褒贬判断。反方可以是斯皮瓦克《三个女性文本与帝国主义批评》（如能找到中译，也衔接第11站），或者你自己写一段对伍尔夫的反驳。回读伍德论不可靠叙述的部分。
- 输出：比较评论：两部作品的叙述者设置如何影响读者对主人公的信任。工具：不可靠叙述、嵌套叙述。

**8｜时间与意识**
- 精读：《追忆似水年华》第一卷（周克希译）；《达洛维夫人》（选近年权威译本，试读比对）；《雪国》（叶渭渠与林少华译对读，林译文风极个人化，很适合练"译本如何改变文本"）。
- 范文 / 反方：纳博科夫论普鲁斯特（《文学讲稿》）；反方是本雅明《普鲁斯特的形象》。它替换了原计划的《论波德莱尔的几个主题》，因为这一篇和你读的是同一位作家。
- 输出：评论普鲁斯特的"绵密唤醒"与川端的"留白克制"；仿写300字。工具：非自愿记忆、意识流两种模式。

**9｜荒诞与现代性**
- 精读：《变形记》《审判》（《卡夫卡全集》，叶廷芳主编）；《局外人》（郭宏安与柳鸣九译对读）；鲁迅《呐喊》《彷徨》（原文）；果戈理《狂人日记》（与鲁迅同名篇对读）。原计划把鲁迅算作"零度写作"，我觉得不贴切：零度写作（巴特）指的是《局外人》那种取消修辞的"白色写作"，而鲁迅的反讽和议论恰恰有温度。鲁迅与果戈理有实际的影响关系，比与卡夫卡更扎实。
- 范文 / 反方：加缪《卡夫卡作品中的希望与荒诞》；反方是博尔赫斯《卡夫卡及其先驱》。鲁迅一侧读夏志清《中国现代小说史》论鲁迅的一章，他的观点鲜明、也有立场偏见，最适合练"评价"与"立场"的区分，可再对照李欧梵《铁屋中的呐喊》。
- 输出：比较两篇同名《狂人日记》；再写一篇卡夫卡评论，在加缪与博尔赫斯之间说明你站哪边、为什么。工具：白色写作、荒诞。

**10｜打破时间与空间**
- 精读：《百年孤独》（范晔译，与高长荣译对读开篇）；《喧哗与骚动》（李文俊译）或《尤利西斯》选章（萧乾、文洁若译与金隄译对读）。呼应：《奥德赛》→《尤利西斯》，回看第3站，写它如何改造史诗框架；《红楼梦》→《百年孤独》，家族史。原计划写的"多重不可靠叙述"不太贴合《百年孤独》，它的叙述者恰恰是全知而笃定的，技法是预叙（"多年以后……"）、循环和一本正经的语气；《喧哗与骚动》才适合谈多重视角。
- 范文 / 反方：《番石榴飘香》（马尔克斯自述）当作"待检验的证词"：他说自己怎么写，你在文本里能验证吗？
- 输出：分析"循环时间"具体靠哪些句法与结构手段实现，而不是泛谈"魔幻现实主义"。工具：预叙、循环时间、多视角。

**11｜殖民之后**
- 精读：阿契贝《瓦解》（中译名不一，选近年版本）；康拉德《黑暗之心》；鲁西迪《午夜之子》；马哈福兹《开罗三部曲》选读（中译本较少、质量参差，试读后决定）。
- 范文 / 反方：萨义德《东方学》导论；阿契贝《非洲的一种形象》批评《黑暗之心》。这一对本身就是"审美评价 vs 权力批判"的现成争议。
- 输出：评论《黑暗之心》，既谈技法，又不回避阿契贝的指控；不必选边，但必须说明判断依据。另保留原计划的比较：奥贡喀沃与索福克勒斯式悲剧英雄。

**12｜终点：没有定论的新作**
- 读：近十年出版的新书，中文原创一两部、译作一两部，最好是你没听过口碑的。
- 方式：先写评论，再去读别人的评论。
- 输出：3篇评论；回头对照第1站的微评，看自己的判断标准变了什么。

评论词汇表每站新增2到3个条目，十二站下来大约三十个。走完一轮之后，可以用同一套流程再开第二轮，换成日本、拉美或当代中文的作品。
